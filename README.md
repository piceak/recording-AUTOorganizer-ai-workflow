具体流程，本文以课堂笔记为例子做讲解

**前期准备工作（必做）**

在Obsidian中打开一个仓库，

下载坚果云插件

在你的pc端和手机端登录同一个坚果云账户，

选择需要同步的文件夹

双端都选择双向同步，自动同步，间隔为5分钟，启动后1秒钟自动同步，

保持pc端和移动端的后台，pc端如果想要自动，那么需要设置不能进入睡眠

{参考}同步的文件夹内最好设置许多独立的课程子文件夹，在其中建立对应的课程的md文件和笔记md文件，笔记文件的名字默认是课程名+笔记（例 子为 参考课程笔记.md)

打开Zcode，选择左侧的自动化，同时把 ZCode 的工作区设为前面配好的同步文件夹

参考prompt与skills与脚本见目录，****注意skills中的文件路径需要你自己设置***

在你需要的时间段分别设置标记任务和笔记任务，建议笔记任务在标记任务的20分钟后

Zcode中，SKILL.md 必须在 .agents/skills/note-annotate/ 和 .agents/skills/note-digest/ 这样的结构里才被识别，要注意放置路径

courses.json 需要按你自己的课程生成。 

在 ZCode 里对你的模型说：

扫描本工作区根目录下的所有课程文件夹（每个文件夹里有一个与文件夹同名的 .md 讲稿），把所有课程文件夹名写进 _system/courses.json，格式为：{"courses": ["课程名1", "课程名2", ...]}

之后每开一门新课，让它把这个课名加进列表即可。

**开始第一步自动化**

微信输入法3.5.3及以上版本 录音，每间隔10分钟暂停一下，以保证自动整理稿子的功能正常

录完之后，放着，等待标记任务拉起，在此之后就可以啦。

**笔者超级建议的几个小tips，关乎于日常使用**

微信输入法有时候会因为网络问题而自动关闭，记得时常查看移动端录音情况，且录音能当字幕看（）

微信输入法一定要更新，老版本会出现一些很严重的问题

**部分技术细节**

用 state.json 给每门课记状态（已标记未笔记 / 已完成），两个定时任务靠它判断这门课这轮该干嘛，避免重复处理

校验脚本强制核对"存疑待查条目数 ≤ 原文打标数"，不配平就判失败重做，防止 AI 漏标偷懒
